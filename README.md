# Birthday & Premium Reminder 生日与保费提醒

A phone-friendly web app. Load your weekly Policy Listing PDF and it lists this week's customer birthdays, premiums due soon and overdue premiums, with English and Chinese messages and a birthday card ready to send on WhatsApp.

- **Use it:** open `reminder-app.html` in a browser, or use the live link: https://claude.ai/artifact/FUjRb221CMVvRjmKczVqAN
- **How to use:** [HOW-TO-USE.md](HOW-TO-USE.md) · for agents: [FOR-AGENTS.md](FOR-AGENTS.md)
- **What was decided and why:** [PROJECT-NOTES.md](PROJECT-NOTES.md)

Customer data is processed only on your device. This repository holds no customer data, so never upload policy listings or customer files here.
